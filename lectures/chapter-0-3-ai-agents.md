## Итог главы

Чат возвращает текст на вопрос, помощник встроен в редактор, агент выполняет задачу по шагам с инструментами. В курсе ИИ применяется в двух местах: помощник разработчика с первой пары и агент внутри проекта, который собирает подробности о тревогах через функции агента-сторожа и составляет текст для человека. Режим задания — Р0, Р1 или Р2 — определяет, сколько работы можно поручить ИИ. Ошибки ИИ в системном коде находятся приборами: счётчик дескрипторов, AddressSanitizer, коды ошибок, сверка со служебными программами. Код принимается по списку из восьми пунктов, и за каждую строку отвечает тот, кто код сдал.
