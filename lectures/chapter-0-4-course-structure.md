## Итог главы

Дисциплина учит понимать, что происходит внутри операционной системы во время работы программы, получать эти сведения из кода на C через системный интерфейс, проверять их приборами и отдавать моделям ИИ. Курс идёт для трёх систем: Windows, macOS и Linux. Весь курс пишется агент-сторож: ядро на C вызывает системные функции, мозг на Python принимает решения и связывает агент с n8n, ИИ-агентом и MCP. Модели ИИ используются с первой пары в трёх местах: помощник разработчика в редакторе, модель в n8n, которая составляет текст тревоги, и ИИ-агент, который собирает подробности через функции агента-сторожа. За 24 пары агент получает 13 проверок, и нарушитель в GitHub Actions подтверждает их все на трёх системах после каждой отправки кода. Курсовая работа — агент со всеми проверками, своей проверкой, своим инструментом для ИИ-агента и защитой.
