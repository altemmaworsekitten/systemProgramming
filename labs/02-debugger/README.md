# ЛР 2. Программа в отладчике

Пара 2 · перед главой 1.1 · [пошаговая работа с кадрами](https://maximbytecamp.github.io/sysprog_makarov/temy/09-laboratornaya-2/index.html)

Маленькая программа на C проходится по шагам в отладчике VS Code: точка останова, шаг с обходом
и с заходом в функцию, переменные до и после присваивания, массив по байтам, Watch в цикле,
стек вызовов и машинный код одной строки.

## Что сдать в этой папке

| Файл | Что в нём |
|---|---|
| `debug.c` | программа из раздела «Подготовка» |
| `.vscode/launch.json`, `.vscode/tasks.json` | настройки запуска и сборки для своей системы |
| `report.md` | заполненный бланк отчёта |

Собранную программу (`debug`, `debug.exe`, `debug.dSYM`, `.pdb`, `.obj`) не добавляйте: её исключает `.gitignore`.

## Проверка

После отправки GitHub Actions собирает `debug.c` с отладочными сведениями, запускает и ищет в выводе
строку `agent: total=6 area=12`. Результат — вкладка **Actions** → **Проверки**.

Коммит: `labs 02: отладчик, отчёт`.
