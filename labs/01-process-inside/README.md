# ЛР 1. Процесс изнутри

Пара 1 · задание к модулю 0 · [пошаговая работа с кадрами](https://maximbytecamp.github.io/sysprog_makarov/temy/05-laboratornaya-1/index.html)

Своя программа на C и та же функция из Python запускаются и рассматриваются в мониторе процессов:
номер процесса, память, дескрипторы, библиотеки, завершение из монитора и обычный выход.

## Что сдать в этой папке

| Файл | Что в нём |
|---|---|
| `hello.c` | программа из главы 0.1, §4, для своей системы |
| `hello.py` | та же функция через `ctypes` |
| `report.md` | заполненный бланк отчёта |

Код программ — в разделе «Подготовка» лабораторной работы, вариант для своей системы выбирается
переключателем вверху страницы.

## Проверка

После отправки GitHub Actions собирает `hello.c`, запускает `hello.py` и ищет в выводе строки
`agent v0, pid=…` и `agent v0 (python), pid=…`. Результат — вкладка **Actions** → **Проверки**.

Коммит: `labs 01: hello.c, hello.py, отчёт`.
