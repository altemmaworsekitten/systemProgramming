# ЛР 3. Библиотеки программы

Пара 3 · перед главой 1.2 · [пошаговая работа с кадрами](https://maximbytecamp.github.io/sysprog_makarov/temy/10-laboratornaya-3/index.html)

Какие библиотеки записаны в файле программы и в интерпретаторе Python, какие загружены в работающий процесс
и как Python загружает новую библиотеку через `ctypes` и вызывает её функцию.

## Что сдать в этой папке

| Файл | Что в нём |
|---|---|
| `libs.c` | программа из раздела «Подготовка» |
| `report.md` | заполненный бланк отчёта |

Собранную программу (`libs`, `libs.exe`, `.obj`) не добавляйте: её исключает `.gitignore`.

## Проверка

После отправки GitHub Actions собирает `libs.c` (в Linux с ключом `-lm`), запускает и ищет в выводе
строку `sqrt(2) = 1.414214`. Результат — вкладка **Actions** → **Проверки**.

Коммит: `labs 03: библиотеки, отчёт`.
