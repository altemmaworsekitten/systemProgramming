# Лабораторные работы

Каждая пара начинается с лабораторной работы в программах системы. Одна работа — одна папка `NN-<тема>`.
Когда работа выдана, преподаватель дописывает строку в таблицу ниже. Имя папки берите из таблицы.

| Папка | Работа | Пара |
|---|---|---|
| [`01-process-inside`](01-process-inside/README.md) | [ЛР 1. Процесс изнутри](https://maximbytecamp.github.io/sysprog_makarov/temy/05-laboratornaya-1/index.html) | 1 |

## Что лежит в папке работы

| Файл | Что в нём |
|---|---|
| `README.md` | что сделать и что сдать |
| `report.md` | бланк отчёта: пропуски `___` заполняются числами и именами с вашего экрана |
| `.c`, `.py` | код работы, если он есть |

Код пишется для своей системы. Проверки в GitHub Actions собирают его на сервере с той же системой,
серверы с другими системами его пропускают.
