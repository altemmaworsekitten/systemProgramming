## Что лежит в папке работы

| Файл | Что в нём |
|---|---|
| `README.md` | что сделать и что сдать |
| `report.md` | бланк отчёта: пропуски `___` заполняются числами и именами с вашего экрана, внизу — подписи и ссылки на снимки |
| `screenshots/` | заглушки снимков экрана: каждая заменяется своим снимком с тем же именем |
| `.c`, `.py` | код работы, если он есть |

Код пишется для своей системы. Проверки в GitHub Actions собирают его на сервере с той же системой,
серверы с другими системами его пропускают.
