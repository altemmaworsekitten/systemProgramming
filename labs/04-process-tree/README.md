# ЛР 4. Дерево процессов

Пара 4 · перед главой 2.1 · [пошаговая работа с кадрами](https://maximbytecamp.github.io/sysprog_makarov/temy/13-laboratornaya-4/index.html)

Монитор системы показывает процессы деревом: с какого процесса начинается система, кто родитель терминала
и браузера, как узнать родителя командой и что происходит с процессом, когда его родитель завершается.

## Что сдать в этой папке

| Файл | Что в нём |
|---|---|
| `report.md` | заполненный бланк отчёта |
| `screenshots/` | 7 снимков экрана: свой снимок сохраняется поверх заглушки с тем же именем |

Код в этой работе не пишется: все команды набираются в терминале.

## Проверка

После отправки GitHub Actions проверяет снимки: в `screenshots/` не должно остаться заглушек.
Результат — вкладка **Actions** → **Проверки**.

Коммит: `labs 04: дерево процессов, отчёт`.
