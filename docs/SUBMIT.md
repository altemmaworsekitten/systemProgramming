# Как сдавать работы

Пошаговая инструкция с картинками для всех случаев — на сайте курса:
[работа с репозиторием](https://algorthimization-course-vvodnoe.vercel.app/dup02-vvedenie-v-python/repozitoriy/index.html). Она снята на курсе Python: там репозиторий называется `python-start`,
здесь — `sysprog-start`, порядок действий тот же. Здесь — правила, которые проверяет преподаватель.

## Куда класть работу

| Работа | Папка | Пример пути |
|---|---|---|
| лабораторная работа | `labs/NN-<тема>/` | `labs/01-process-inside/report.md` |
| код агента на C | `agent/core/` | `agent/core/processes.c` |
| код агента на Python | `agent/brain/` | `agent/brain/brain.py` |
| домашнее задание | `homework/NN-<тема>/` | `homework/01-c-pointers/task_01.c` |
| тест | `exams/quiz-NN-…/README.md` | код результата в таблице |
| курсовая работа | `exams/coursework/` | `exams/coursework/report.md` |

Имя папки для новой работы берётся из таблицы в `labs/README.md` и `homework/README.md`:
преподаватель дописывает туда строку, когда выдаёт работу.

## Имена папок и файлов

| Правило | Правильно | Неправильно |
|---|---|---|
| латинские буквы, цифры, `-` и `_` | `hello.c` | `привет.c` |
| без пробелов | `01-process-inside` | `01 process inside` |
| маленькие буквы | `hello.c` | `Hello.C` |
| номер двумя цифрами | `task_07.c` | `task_7.c` |
| файл кода — слова через `_` | `sentry_core.c` | `sentry-core.c` |
| папка — слова через `-` | `01-process-inside` | `01_Process_Inside` |
| имя говорит, что внутри | `processes.c` | `new.c`, `test1.c`, `final2.c` |

Собранные программы (`.exe`, `.obj`, `.o`, `.dll`, `.so`, `.dylib`) в репозиторий не добавляются:
их собирает каждая система сама. Это записано в `.gitignore`.

## Сообщение коммита

Первое слово — папка, затем номер работы и что сделано:

| Работа | Сообщение |
|---|---|
| лабораторная 1 | `labs 01: hello.c, hello.py, отчёт` |
| исправление в лабораторной | `labs 01: исправлен вывод pid` |
| код агента | `agent: список процессов в ядре` |
| домашнее задание | `homework 01: задачи 1–3` |
| тест | `quiz 01: код результата` |

Сообщения `update`, `fix`, `файлы`, `123` не принимаются: по ним нельзя понять, что изменилось.

## Перед отправкой

1. Каждая программа собрана и запущена, вывод совпадает с примерами задания.
2. Файлы лежат в нужной папке, имена по правилам выше.
3. В `report.md` лабораторной заполнены все пропуски `___`.
4. Если использовался ИИ, это записано: в отчёте — строка «ИИ», в коде режима Р2 — журнал работы с ИИ.
5. Работа ушла на GitHub: на странице репозитория виден ваш коммит, во вкладке **Actions** — зелёная отметка «Проверки».

Все работы загружаются в ветку `main`. Отдельные ветки и Pull Request для заданий не создаются.
